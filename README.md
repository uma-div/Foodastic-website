# 🍲 Foodastic - Homemade Pickles Website

A responsive food business website built using HTML, CSS, and Bootstrap.  
This website showcases homemade pickles and allows users to order.

---

## 🚀 Live Demo

🔗 https://uma-div.github.io/Foodastic-website/  
🔗 https://amazing-llama-e8aeda.netlify.app/

---

## ✨ Features

- 🏠 Responsive Navbar and Hero Section  
- 🥭 Product Section with Pickle Cards  
- 📖 About Us Section (Brand Story)  
- 📞 Contact Section with Form  
- 💬 WhatsApp Integration for Direct Orders  
- 📱 Fully Responsive Design  

---

## 🛠️ Tech Stack

- HTML5  
- CSS3  
- Bootstrap 5
